01 — Colourway

The gradient picks the accent,
and the accent picks everything else

The artwork is a radial gradient pushed through an animated displacement map. Its middle stop is also --accent, so choosing a colourway re-tints the toggles, the focus rings, the badges, the danger button and the easing balls in the same frame. One decision, not eleven.

02 — Dither

The other grain: a colour that
holds, then falls apart

The hero panel is continuous tone warped by a displacement map. This is its opposite — a hard ordered break-up, where the fill stays solid and only the edge scatters into loose pixels. One tiled 65×65 PNG of random alpha, added to a radial gradient in the mask, and image-rendering: pixelated so the dots stay dots. Hover any of them and the sweep rolls; it is 400% wide and moves exactly one tile, so there is no seam to catch.

03 — Stacked

Two colours, two bands,
one sweep

A second layer on the same element, its gradient starting where the first one has finished and its mask cut further down, so the two colours meet in a band of mixed pixels instead of a line. The ground colour underneath is the third. Nothing here is an image and nothing is fetched — the only asset is the four kilobytes of noise, inlined.

08 — Questions

Four things people ask
before they paste it in

01 Is there a runtime?

None. The tokens are custom properties and the components are CSS with a handful of class toggles. The only JavaScript on this page opens a dropdown, switches a tab and moves four balls along a track — you can delete all of it and still have the system.

02 Why is the grain an SVG filter and not an image?

Because it has to re-colour with the theme. The gradient is CSS, so the colourway switch changes it instantly; the filter only displaces whatever it is given. An image would have to ship four times and still would not match a custom accent.

03 What happens with reduced motion?

Every transition collapses to 0.01ms and the grain's animated seed is paused, which freezes it on one frame without removing the texture. The page still says everything it said before; it just stops moving while it does.

04 Is any of this real?

No. Grain is a fictional product built as a design demo: the company, the version number, the prices and the component count were all invented for it. Nothing installs, nothing is purchased, and no request leaves this page.
