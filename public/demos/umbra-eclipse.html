Umbra

The inference runtime that gets out of the way.
Models in, tokens out, nothing left running.

Built to disappear

Load once. Serve everywhere.
Pay for none of the waiting.

Umbra keeps weights resident and cold-starts in the time it takes to parse the request, so the runtime stops being the thing you plan around.

You have been paying for cold starts

Weights stay mapped and the graph stays compiled between calls. The first request after an idle hour costs what the second one does.

resident
01 spec

One artifact, any silicon

The same build runs on the laptop you developed it on and the rack you deployed it to. No per-target rebuild, no quiet precision swap.

portable
02 spec

Nothing left running

Idle means idle. When traffic stops the runtime releases and the meter stops with it, which is the part every other bill forgets.

idle
03 spec

It runs where you already are.

Umbra picks its backend when the model loads and never asks you to rebuild for the box in front of it. Develop on the laptop, ship the same artifact to the rack.
